## 1. 目標與成功樣貌

使用者在交易頁就能：

1. 選一個人，先看到「目前小明欠你 $120」，再記借出、借入、對方還我、我還對方、對方幫我付。
2. 送出前看到「記完後：小明欠你 $9」。
3. 還款時勾「以此結清」，看到「記完後兩清，差額 −3（少收 3 元）」。
4. 在借還檢視看每個人的往來餘額；點一個人，看全部往來紀錄與當時的累計餘額，並能免除、改、刪。
5. 在明細看到「借出 · 小明」「餐飲 · 小明代付」，點下去就打開那個人的往來帳。

設計原則（開發者 2026-09-24）：**以使用者的角度考量，不能繁瑣，但不能因此失去嚴謹，因為牽涉到錢。**

### 範圍外

- 多人分帳、對象合併（後端也沒有）。
- 好友與連動（3b-2）。
- 首頁 dashboard 的借還卡片。

## 4. 畫面規格

### 4.1 「借還」分頁（W10～W12、W16）

由上往下：

1. **對象**：輸入框，提示既有對象的名字（`GET /counterparties`）。
   - 輸入的名字（去掉前後空白）對得上既有對象 → 下方顯示「目前小明欠你 $120」「目前你欠小明 $11」或「目前和小明兩清」。
   - 對不上 → 顯示「新對象，送出時建立」。
2. **種類**：5 個選項，一律可選。
3. **欄位**：

   | 欄位       | 借出／借入／對方還我／我還對方   | 對方幫我付         |
   | ---------- | -------------------------------- | ------------------ |
   | 金額       | 必填                             | 必填（你的那一份） |
   | 日期       | 預設今天                         | 預設今天           |
   | 帳戶       | 不預選、必填（非連動帳本不顯示） | 不顯示             |
   | 分類       | 不顯示                           | 支出分類，必填     |
   | 備註       | 選填                             | 選填               |
   | 不記入帳本 | 勾選框，預設不勾；勾了帳戶停用   | 不顯示             |
   | 以此結清   | 只有對方還我、我還對方           | 不顯示             |

   帳戶欄的標籤依種類寫：借出「從哪個帳戶借出」、借入「借到的錢進哪個帳戶」、對方還我「收進哪個帳戶」、我還對方「從哪個帳戶付出」。

4. **預覽**（W16）：填了金額就顯示一行，例如「記完後：小明欠你 $9」「記完後：你欠小明 $11」「記完後：兩清」。勾了以此結清時改成「記完後兩清，差額 −3（少收 3 元）」或「…差額 +2（多收 2 元）」；我還對方時寫「少付／多付」。對象是新對象時，目前餘額當 0 算。
5. **送出**：`POST /debt-entries`。`record` 一定給（物件或 `null`）；新對象用 `{ name }`，既有對象用 `{ id }`。成功後清空金額與備註，**保留對象與種類**，方便連續記同一個人。

### 4.2 借還檢視（W13）

- 交易頁的「明細／借還」切換（沿用，`?view=debts`）。
- **對象清單**：每人一列，顯示名字與往來餘額（「欠我 $9」「我欠 $11」「兩清」）。餘額不為 0 的在前（後端排序）。每頁 20 人。
- 點一列 → 右側欄顯示該對象的往來帳（§4.3）。
- 沒有任何對象時：「還沒有借還紀錄，從『新增交易 → 借還』開始記第一筆」。
- 上方一行小字「借還紀錄不分帳本」（沿用）。

### 4.3 對象往來帳（右側欄）

- 標題：對象名字，旁邊一顆「改名」。改名撞名時顯示後端的錯誤訊息。
- 往來餘額（大字）：「小明欠你 $9」／「你欠小明 $11」／「兩清」。
- 動作：
  - **記一筆**：打開新增表單的「借還」分頁，對象已帶入。
  - **免除剩餘**：只在對方欠你時顯示。確認視窗寫明「小明欠你的 $50 將歸零，不產生交易；之後可以刪除這筆免除來還原」。
  - **刪除對象**：只在沒有任何往來紀錄時顯示。
- **往來紀錄**（新到舊，分頁）：每筆一列，顯示日期、種類（借出、借入、對方還我、我還對方、幫我付、結清差額、免除）、金額（帶正負號，正數＝對方多欠我）、當時累計餘額（`balanceAfter`）、備註；「不記入帳本」的加標籤「未記帳」。
  - 每列有「刪除」；一般紀錄另有「修改」（小視窗，改金額、日期、備註）。調整紀錄只有刪除。
  - 刪除確認寫明「對應的交易會一起刪除，帳戶餘額與往來餘額會回到記這筆之前」。

### 4.4 明細（W14）

- 借還交易：標題寫「借出 · 小明」這類「型別 · 對象」。
- 代付支出：標題照一般支出寫分類，後面加「· 小明代付」。
- `debt` 有值的列（自己的借還交易與代付支出）：點了打開該對象的往來帳（§4.3）；沒有刪除按鈕（後端會回 409）。
- `debt` 為 `null` 的借還交易（帳本裡別人的）：不可點、沒有可點樣式（沿用）。

### 4.5 右側欄在切換檢視時維持原狀（W15）

切換「明細／借還」會改網址。右側欄目前的規則是「每次導覽就收起」（2i SC-44）。改成：**只有這個切換**帶一個導覽旗標，右側欄看到旗標就維持原狀。換到別的頁面、瀏覽器上一頁／下一頁，照舊收起。

### 4.6 錯誤訊息

| 代碼                           | 訊息                                               |
| ------------------------------ | -------------------------------------------------- |
| `COUNTERPARTY_NAME_TAKEN`      | 已經有同名的對象了，換一個名字。                   |
| `COUNTERPARTY_HAS_ENTRIES`     | 這個對象還有往來紀錄，不能刪除。                   |
| `NOTHING_TO_FORGIVE`           | 對方目前沒有欠你錢，沒有東西可以免除。             |
| `DEBT_ENTRY_NOT_EDITABLE`      | 結清差額與免除不能修改，要調整請刪除後重記。       |
| `DEBT_TRANSACTION_READ_ONLY`   | 這筆交易來自借還，請到借還的往來帳修改。（改寫）   |
| `LEDGER_HAS_DEBT_TRANSACTIONS` | 這本帳本有借還交易，不能刪除。請改用封存。（沿用） |

移除逐筆債務版的 `DEBT_OVERPAYMENT`、`DEBT_NOT_OPEN`、`DEBT_NOT_FORGIVABLE` 訊息。

## 5. 可驗證的成功條件

- **SC-W20**：借還分頁輸入「小明」借出 120（現金）→ 送出前預覽「記完後：小明欠你 $120」；送出後現金 −120，明細出現「借出 · 小明」。
- **SC-W21**：再選「小明」→ 顯示「目前小明欠你 $120」；選借入 111（現金）→ 預覽「記完後：小明欠你 $9」；送出後借還檢視只有一列「小明　欠我 $9」。
- **SC-W22**：選「小明」、對方還我 5、勾以此結清 → 預覽「記完後兩清，差額 −4（少收 4 元）」；送出後借還檢視顯示「兩清」，往來帳有「結清差額 −4」，現金 +5。
- **SC-W23**：輸入「小華」、對方幫我付 400、分類餐飲 → 沒有帳戶欄；送出後明細出現「餐飲 · 小華代付」400，帳戶餘額不變；借還檢視「小華　我欠 $400」。
- **SC-W24**：在明細點「借出 · 小明」→ 右側欄打開小明的往來帳，紀錄依新到舊顯示，`balanceAfter` 依序是 0、4、9、120。
- **SC-W25**：在小明的往來帳刪除「結清差額」→ 餘額回到欠我 $4；「免除剩餘」→ 兩清；刪除那筆免除 → 回到欠我 $4。
- **SC-W26**：修改借出金額 120 → 150 → 現金再 −30，往來餘額跟著變。
- **SC-W27**：新增表單開著時切換「明細／借還」，右側欄不收起、已填的欄位還在；換到帳戶頁再回來，右側欄是關的。
- **SC-W28**：帳戶欄沒有預選；沒選不能送出。
- **SC-W29**：前端除了 W16 的預覽，沒有計算往來餘額（程式審查）。
- **SC-W30**：`pnpm lint / typecheck / test / build / format:check` 與兩套 e2e 全綠。

## 7. 界線

- **Always**：顯示的餘額取自 API；送出時 `record` 一定明確給；刪除與免除先確認。
- **Ask first**：任何後端變更（先改 `phase-3b-debts.md`）；新增套件；側欄或首頁的改動。
- **Never**：除 W16 預覽外在前端計算往來餘額；讓借還交易或代付支出走一般交易的編輯或刪除。
