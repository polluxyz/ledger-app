## 替代方案與取捨

- 趨勢保留長條／折線切換，只拿掉表格：開發者要求合成一張圖（spec 依據）。
- 趨勢合成圖改成橫向捲動：開發者選 12 個月擠一張細柱（spec 依據）。
- 手機兩欄改成清單在上：開發者選圖在上、清單在下。
- 用 CSS `order` 調換手機順序：鍵盤與讀屏順序會和畫面不一致。改成依寬度改渲染順序（決策 416）。
- 個人資料套用 SH-2 共用表單骨架：會連帶影響其他表單，超出範圍（決策 421）。
- 身份彈窗也加品牌欄：彈窗寬度不夠，會壓縮表單（決策 420）。
- 分 3 個 PR：開發者選 1 個 PR 分 3 組 commit，方便一起看 demo（決策 423）。
