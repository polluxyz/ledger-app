# Spec：階段三 (3l) — 刪除私人帳本時搬走交易、複製交易

> 狀態：**草稿，待核可**
> 依據：
>
> - 2d §8「複製交易到其他帳本」：私人帳本想變共享的唯一解法，「本步之後儘早排入」。
> - 3k 範圍外「私人帳本刪除時合併」。
> - 開發者 2026-10-19：「先把複製交易的功能完成，要完成才能比較完整的測試功能」。前提清單的回答：
>   - 從共享帳本直接搬走會影響其他人，所以搬移只從私人帳本出發。
>   - 「有兩種情況：第一種是刪除帳本，那原本帳本的交易一定是搬過去另一個帳本；第二種是單純的複製交易（可能有重複的交易想要另外記一筆，那就用複製功能）」。
>   - 私人帳本裡可以帶走的交易：全部。
>   - 刪除時「可以選擇」搬或不搬；不搬的照 3k 顯示帳戶影響。
>   - 複製是新的一筆，日期是今天；可以記到別本。
>
> 前置：3k（#137）已合併並部署到 dev。
> 改寫的既有決策：3j 決策 186（私人帳本刪除一律撤銷）、2d §8 的「複製交易到其他帳本」改成本 spec 的兩個功能。
> 執行順序：本 spec（含預覽頁）→ plan 與 todo → 一個 PR（後端＋畫面）。

---

## 1. 目標與成功樣貌

現在刪除私人帳本，交易跟著帳本一起消失，記在裡面的借還被撤銷。想把私人帳本改成共享帳本的人，只能新建一本共享帳本、舊的交易全部重記。另外，同一筆消費常常重複發生（每天的早餐、每月的訂閱），現在只能每次從頭填。

本步做兩件事：

- **刪除私人帳本時，可以把交易搬到我的另一本帳本**，包括共享帳本。搬過去的交易就是原來那幾筆，帳戶餘額不變、可以照常修改。
- **複製交易**：從一筆交易開出新增表單，內容先帶好，改完存成新的一筆。

用一個例子貫穿全篇。我有私人帳本「日常」與「旅行基金」，還有共享帳本「家用」（我、小美）。「旅行基金」裡有：

| #   | 交易     | 帳戶                        | 金額                                 |
| --- | -------- | --------------------------- | ------------------------------------ |
| 1   | 機票訂金 | 信用卡                      | −$5,000                              |
| 2   | 存入     | 現金 → 旅行帳戶（帳戶互轉） | $2,000                               |
| 3   | 借給阿德 | 現金                        | −$1,000（個人借還，阿德欠我 $1,000） |

本步完成後：

1. 我在「旅行基金」按「刪除帳本」→ 對話框「刪除「旅行基金」」，「搬到」下拉預設是我的第一本其他帳本「日常」，帳本名稱欄、「取消」「封存」「刪除」。全部搬走時帳戶不變，不列帳戶段。
2. 我把「搬到」改成「家用」，打名稱、按「刪除」→「家用」多了 3 筆。小美看得到機票訂金與存入，付款人是我、沒有分帳；借給阿德是我的個人借還，只有我看得到（同 3b）。我的信用卡、現金餘額不變；借還頁的阿德照樣是「阿德 ─▶ 我 $1,000」。
3. 換一個情況：在對話框點「選擇交易」，取消勾選「機票訂金」→ 帳戶段出現「信用卡 −$5,000 → $0」。刪除後只有存入與借給阿德搬走，機票訂金跟帳本一起刪掉。
4. 「搬到」選「不搬」→ 等於全部取消勾選：帳戶段列出所有會變的帳戶，往來段列出被撤銷的借還（「阿德 $1,000 → $0」），就是現在 3j 的刪除。
5. 在「日常」打開「早餐 $80 現金」的編輯面板，按「複製」→ 新增表單打開，帳本「日常」、日期今天、金額 $80、分類早餐、帳戶現金、名稱早餐都帶好。按「新增」→ 多一筆今天的早餐，現金再扣 $80。
6. 複製時把帳本換成「家用」→ 分類改成「家用」裡同名的「早餐」（沒有同名的就空著讓我選），其他欄位不變。

### 範圍外

- **從共享帳本搬走交易**：會影響其他成員的帳與餘額。要把自己的帳帶出共享帳本，用 3k 的退出並合併。
- **不刪帳本、只搬選取的交易**（批次搬移）：開發者這次只要刪除時搬與複製。要的話另案。
- **一次複製多筆**、**定期自動記帳**：另案。
- **複製借還、結清、合併來的「我付、有分帳」**：它們各有記法（借還頁、結清按鈕），複製按鈕不出現。

## 4. API

### 4.1 `POST /ledgers/{ledgerId}/leave-preview`、`POST /ledgers/{ledgerId}/leave`（改）

- 私人帳本：只接受 `deleteLedger: true`；沒帶 → 400。共享帳本照 3k。
- 只有擁有者（私人帳本的擁有者就是我）；封存的 → 預覽 `blockedBy: 'LEDGER_ARCHIVED'`、執行 409（同 3k）。
- 預覽的 `items` 照決策 211 分組；`carryOvers` 恆為空陣列（私人帳本沒有帳本裡的人）；`withdrawals` 是沒勾的借還。
- 執行：分類對應 → 勾選的改 `ledgerId` → 沒勾的照 3j 決策 186 撤銷 → 刪帳本。
- 錯誤：目標帳本不能記帳 → 403；目標是自己 → 400；`confirm` 不等於帳本名稱 → 400（同 3k）。

### 4.2 shared

- `LeaveRequest`、`LedgerLeavePreview` 不加欄位；註解補「私人帳本刪除也用這組型別，搬移不是合併」。
- 交易回應不加欄位：搬過去的交易就是原交易，不標來源。

## 5. 成功條件

- **SC-N1**（全部搬）：§1 的旅行基金刪除並搬到日常 → 3 筆在日常，id 不變；信用卡、現金餘額不變；阿德往來餘額不變、往來紀錄可以照常改；旅行基金查不到（404）。
- **SC-N2**（搬到共享帳本）：搬到家用 → 小美看得到機票訂金與存入、付款人是我、她的帳與餘額不變；看不到借給阿德。
- **SC-N3**（部分搬）：取消勾選機票訂金 → 預覽帳戶段「信用卡 −$5,000 → $0」，執行後結果與預覽一致。
- **SC-N4**（不搬）：結果與 3j 刪除私人帳本（`withdrawDebts=true`）相同：帳戶影響一致、借還撤銷、連動的對方收到撤銷。
- **SC-N5**（分類）：目標帳本有同名分類就用、沒有就新建一個同名同圖示的；不會指到被刪帳本的分類。
- **SC-N6**（綁在一起）：有結清分支的還款、個人分帳、合併來的「我付、有分帳」，勾或不勾都整組一起；不會留下一半。
- **SC-N7**（隔離）：別人的私人帳本預覽與執行 → 404；目標是我沒有寫入權的帳本 → 403；目標是封存的 → 409；搬移只動呼叫者自己的資料。
- **SC-N8**（複製）：§1 的早餐複製 → 新的一筆、日期今天、其他欄位相同，原交易不變；換到家用 → 分類對到同名、付款人是我、沒有分帳。
- **SC-N9**（複製的範圍）：借還、結清、合併來的「我付、有分帳」沒有「複製」按鈕。

## 7. 界線

- **Always**：數字由後端算，預覽與執行同一套計畫；搬移在單一資料庫交易內完成；分類對應到目標帳本自己的分類。
- **Ask first**：改資料模型；開放從共享帳本搬移；一次複製多筆。
- **Never**：前端自己算帳戶影響；搬移時留下指向被刪帳本的分類或交易；複製時沿用另一本帳本的分類 id。
