# 3g 原型：借還頁改版的決定（暫存，定案後併入 spec）

分支 `polluxyz/debts-inline`。開發者 2026-10-07～08 看原型逐步給的回饋，先記在這裡，版面定案後寫進 `docs/specs/phase-3g-*.md` 再開 PR。

## 版面

- 交易頁分頁只剩「明細」「借還」，拿掉「結清」。借還不分帳本。
- 借還的子分頁：「總覽」「個人」「共享」「歷史」。
  - 總覽：每人總額（個人往來＋共享帳本），點對象在列下方展開明細，**沒有任何操作**。
  - 個人：只看個人往來，展開後可記一筆、免除、修改、刪除、分帳。
  - 共享：每本共享帳本一組，只列轉帳（含別人之間），不顯示淨額；**點轉帳**就在下方展開預填的結清表單，沒有「新增結清」「結清」按鈕。
  - 歷史：統一放已還清的往來紀錄與已記的結清；其他地方不再有「歷史」。
- 已還清的判斷：跟某人的往來餘額最近一次歸零，那一筆與更早的紀錄移到歷史（「餘額歸零為界」）。
- 點對象直接在列下方展開（有收合動畫），不開右側欄；「記一筆」也在下方。列右邊沒有展開記號，借貸箭頭靠右。展開區不重複箭頭、不放「往來紀錄」標題。
- 沒指向的共享帳本的人（例如「家用」的小華），列的樣式跟對象列相同。
- 最上排清空（留給 AI 功能）；帳本切換與「＋ 新增交易」移到「明細」那一排，只在明細顯示。其他頁面頂列的東西也移進內容。
- 永遠預留捲軸寬度（`scrollbar-gutter: stable`），切換分頁不左右跳動。

## 往來紀錄的符號（2026-10-08，提案頁 `docs/artifacts/step-debts-entry-symbols.html`）

- **D1 選 A**：每筆紀錄畫一條金色虛線箭頭，表示「這一筆誰給了誰」（現金或代付都算）。方向＝API `delta` 的正負號（正＝我 → 對方）。規則一句話：**箭頭指向誰，誰就欠對方**。
  - 借錢：線上沒有圖示。還款：線上放「回頭」圖示。代付、代收：線上中間放收據圖示（「他付了帳，算在我頭上」）。結清差額、免除：不畫箭頭，只有打勾圖示＋金額。
  - 開發者的疑問：代付時我的錢沒有變，還算流向嗎？回答：箭頭表示價值從誰給了誰，不是錢包增減；錢包增減看「明細」。看過原型若仍覺得兩種箭頭會亂，可改 B（只有「誰欠誰」一種箭頭＋增減）。
- **D2**：拿掉每筆下面的「餘額」。
- **D3**：展開區裡的共享帳本改成同樣的小頭貼箭頭（實線＝欠），帳本名稱當小標。開發者備註：盡量統一作法，使用者習慣後就方便。
- 金額不帶正負號；完整說明（例如「我幫小明付」）放在列的可存取名稱與滑鼠提示。

## 原型限制（正式版要處理）

- 已還清分組、個人分頁的 `balance ≠ 0` 過濾暫時在前端，只用 API 回傳的值判斷；正式版移到後端（API 變更，要先問）。
- 往來紀錄一次只抓 100 筆。
- 共享分頁只列目前還在的共享帳本；歷史裡的結清還不能編輯。
- Web e2e 尚未跟上（借還、連動、共享帳本分帳、3f 主線、版面）。
