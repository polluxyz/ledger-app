# 首頁收支圖卡視覺漏項補正

使用者提供已核可預覽，指出正式頁面漏了圖示與背景。此為 2m 視覺實裝漏項修正，依 [spec 第 4 項及 SC-V9](../docs/specs/phase-2m-home-visual-refresh.md) 補齊。

## 範圍與驗收

- 三張卡右上：支出斜上箭頭、收入斜下箭頭、結餘等號，沿用既有 Icon 元件與設計 token。
- 本月結餘：淡金背景、右下雙圓弧；裝飾在獨立裁切層，不裁掉卡片焦點框、拖動控制或影響點擊。
- 對齊參考圖的貨幣符號大小與副標；沿用完整格式化字串的正負號、小數及共享帳本「我」的金額，不改資料來源或計算。
- 驗證正式頁面深淺色、1280／390／309px、卡片拖動與鍵盤，再將實際截圖及 PR 交給 Claude Code 驗收。
- 不改 API、schema、套件、CI、版面資料格式或其他頁面。
