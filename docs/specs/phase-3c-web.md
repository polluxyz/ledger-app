## 1. 目標與成功樣貌

用晚餐 3,000 元、4 人均分的例子：

1. 在記帳表單的支出分頁填金額、分類、帳戶、名稱，打開「分帳」開關，下方列出我與要分的人，每人 $750。按「新增」。
2. 交易列表多一列「晚餐 −$3,000」標「分帳」。點右邊的箭頭往下展開，看到 `小明 ──$750──▶ 我` 這樣的明細。
3. 要改比例：點分帳列的「›」，右側欄滑入「分帳選項」。在比例分頁把我改成 20%，另外三人自動變成各 26.67%。按「儲存」回到表單。
4. 小明先付的情況：點帳戶列右邊的切換圖示，改選付款人「小明」，下方預覽 `我 ──$750──▶ 小明`。
5. 往來帳、對象清單、總覽的待確認卡片，誰欠誰一律用箭頭表示。

### 範圍外

- 共享帳本的分帳畫面與成員之間的結清（`phase-3c-split.md` 決策 87）。
- 計算機鍵盤。

## 3. 可驗證的成功條件

- **SC-W72**：支出表單欄位順序符合 W62；沒有任何「（選填）」字樣。
- **SC-W73**：按切換圖示 → 帳戶下拉換成付款人；選小明、金額 750 → 預覽 `我 ──$750──▶ 小明`（讀屏文字「你欠小明 $750」）；送出打 `POST /splits`，body 的 `payer.counterpartyId` 是小明、名單只有我。
- **SC-W74**：分帳開、金額 3,000、加小明小華阿美 → 名單每人 $750；送出打 `POST /splits`，`method: 'EQUAL'`、名單 4 人、`accountId` 是所選帳戶。
- **SC-W75**：分帳選項：比例分頁我改 20%（3 人）→ 其他兩人自動 40%；改成合計 115% → 顯示「比例合計 115%」、「儲存」停用。「‹」放棄修改。
- **SC-W76**：交易列表的分帳列顯示 `−$3,000`、「分帳」；點「›」展開出 3 行箭頭與「我 $750」；點列本身打開編輯，表單預填名單與分法。

- **SC-W78**：對象清單、往來帳、待確認卡片的餘額都是箭頭，讀屏文字與原本的句子相同。
- **SC-W79**：收到「對方幫我付」的提議 → 展開後有帳本、分類、名稱（預填「晚餐」），沒有帳戶。
