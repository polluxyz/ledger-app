# Spec：2j — 收支統計與資產趨勢（首頁、統計頁）

> 狀態：**核可中**。開發者 2026-10-21 看過預覽頁 v1，要求首頁加資產趨勢圖（§2.4）。§10 的項目交給 2j 分支的 session 跟開發者確認。
> 依據：
>
> - 2i §4.7 與延後項目：首頁 3 張統計卡留著「即將推出」，「彙總的期間、時區與共享帳本權限需要自己的 spec（2j）」。
> - 3b §9、3c §9、3e §9、3h §9 留下的「做統計報表時再決定」。
> - 開發者 2026-10-21：「一般記帳軟體有的功能，我都要有，並且再配合我目前的規劃去適配，看有沒有新的功能也可以加進來。」請 advisor（Codex gpt-6-astra high）研究常見功能、分期、邊界情況後，開發者定案：
>   - 分期照 advisor 的建議（§1 範圍外的表）。2j 只做單一帳本的收支統計，不改資料模型。
>   - 共享帳本的首頁卡：大字是帳本總額，下面小字「我 $X」。個人帳本沒有小字。
>   - 共享帳本沒分帳的收支，每人支出算付款人的（同 3k 合併的規則）。
>   - 首頁卡的「本月」是整個月份，照台灣時間。
>   - 結清差額、呆帳不放「未分類」，用固定的分組（advisor 建議，開發者沒有反對）。
> - 開發者 2026-10-21（看過預覽頁 v1）：「首頁要擺的是一張資產趨勢圖，然後一個本月支出、本月收入、結餘這樣。」原本排在第四期的「帳戶歷史餘額」因此把「資產總額的趨勢」提前到 2j，各帳戶分開的趨勢與淨資產仍在第四期。
> - 與階段四 AI 4a 平行進行。兩者不改資料模型，只在 `app.module.ts`、shared 匯出、側欄各多一行。

## 1. 目標與成功樣貌

首頁的「本月支出」「本月收入」「結餘」從 2i 起一直顯示「即將推出」，因為沒有後端彙總端點。使用者也沒有地方看「錢花在哪裡」「這幾個月是多花還是少花」「家用帳本裡誰花了多少」。

本步做三件事：

- **首頁最上面放資產趨勢圖**：我所有帳戶的餘額合計，近 12 個月每月一個點。
- **首頁 3 張卡顯示真的數字。**
- **新增「統計」頁**：選帳本與期間，看收支摘要、分類、每月趨勢，共享帳本另外看每人支出。

數字全部由後端算。用兩本帳本的例子貫穿全篇，期間都是 2026 年 10 月。

**私人帳本「日常」：**

| #   | 交易                 | 型別       | 金額    | 算不算收支               |
| --- | -------------------- | ---------- | ------- | ------------------------ |
| 1   | 早餐（分類：早餐）   | 支出       | $80     | 算                       |
| 2   | 午餐（分類：午餐）   | 支出       | $120    | 算                       |
| 3   | 薪水（分類：薪資）   | 收入       | $50,000 | 算                       |
| 4   | 現金 → 儲蓄          | 轉帳       | $1,000  | 不算                     |
| 5   | 借給阿德             | 借出       | $1,000  | 不算                     |
| 6   | 阿德還 $93，實收 $90 | 收回＋分支 | $93、$3 | 收回不算；少收 $3 算支出 |
| 7   | 免除小華的 $500      | 呆帳       | $500    | 算支出（3h 決策 162）    |

**共享帳本「家用」（我、小美）：**

| #   | 交易                   | 付款人 | 分帳               | 金額      |
| --- | ---------------------- | ------ | ------------------ | --------- |
| 1   | 晚餐（分類：晚餐）     | 我     | 我 $450、小美 $450 | $900 支出 |
| 2   | 衛生紙（分類：日用品） | 小美   | 不分帳             | $300 支出 |
| 3   | 退費（分類：退款）     | 我     | 不分帳             | $200 收入 |

我的帳戶：「現金」初始餘額 $10,000，「儲蓄」初始餘額 $0。上面兩本帳本 10 月的交易，凡是我付或我收的都走「現金」；轉帳是現金 → 儲蓄。9 月以前沒有交易。

本步完成後：

0. 首頁最上面是資產趨勢圖，2025 年 11 月到 2026 年 10 月。9 月底以前每個點都是 $10,000，10 月底是 $58,190（現金 $57,190＋儲蓄 $1,000）。換帳本時這張圖不變。
1. 我在首頁選「日常」→ 圖下面 3 張卡是「本月支出 $703」「本月收入 $50,000」「結餘 $49,297」。$703＝早餐 80＋午餐 120＋少收 3＋呆帳 500。轉帳、借出、收回都不算。
2. 首頁換成「家用」→ 「本月支出」大字 $1,200、下面小字「我 $450」；「本月收入」$200、「我 $200」；「結餘」−$1,000、「我 −$250」。
3. 點任何一張卡 → 進統計頁，帳本是「家用」、期間是 2026 年 10 月。
4. 統計頁的分類區（支出）：晚餐 $900（75%）、日用品 $300（25%）。切到「我」→ 晚餐 $450（100%）。
5. 「日常」的分類區（支出）：呆帳 $500、午餐 $120、早餐 $80、結清差額 $3。
6. 趨勢區列出 2025 年 11 月到 2026 年 10 月共 12 個月的收入與支出長條。沒有交易的月份是 0。
7. 「家用」多一個每人區：我 支出 $450、收入 $200；小美 支出 $750（晚餐 450＋衛生紙 300）、收入 $0。兩人加起來等於帳本總額。
8. 點分類區的「晚餐」→ 交易頁打開，帳本「家用」、篩選「晚餐」與 10/1～10/31。

## 4. API

都在 `StatisticsModule`，`@ApiTags('statistics')`。權限：我是這本帳本的成員（任何角色，含檢視者）；不是成員或已退出 → 404。

### 4.1 `GET /ledgers/{ledgerId}/statistics`

查詢參數：

| 參數          | 型別               | 說明                                                            |
| ------------- | ------------------ | --------------------------------------------------------------- |
| `from`        | `YYYY-MM-DD`       | 起日，包含，台灣時間                                            |
| `to`          | `YYYY-MM-DD`       | 迄日，包含，台灣時間。`to` 早於 `from`、或跨度超過 366 天 → 400 |
| `perspective` | `LEDGER` \| `MINE` | 分類區用哪一種數字，預設 `LEDGER`。私人帳本兩者相同             |

回應：

```ts
interface StatisticsTotals {
  income: Cents;
  expense: Cents;
  /** income − expense，可以是負數。 */
  net: Cents;
}

type StatisticsGroupKind =
  'CATEGORY' | 'DIFFERENCE' | 'BAD_DEBT' | 'DEBT_FORGIVEN' | 'UNCATEGORIZED';

interface StatisticsGroup {
  kind: StatisticsGroupKind;
  /** 只有 `CATEGORY` 有值。 */
  category: { id: string; name: string; icon: CategoryIcon | null } | null;
  /** 依 `perspective` 的金額，單位：分。 */
  amount: Cents;
}

interface StatisticsPerson {
  personId: string;
  /** 顯示用的名字，同借還頁的規則。 */
  name: string;
  isMe: boolean;
  expense: Cents;
  income: Cents;
}

interface LedgerStatistics {
  ledgerId: string;
  from: string;
  to: string;
  /** 兩種數字都回，首頁卡片不用打兩次（決策 229）。 */
  ledger: StatisticsTotals;
  mine: StatisticsTotals;
  /** 依 `amount` 由大到小，金額 0 的不列。 */
  expenseGroups: StatisticsGroup[];
  incomeGroups: StatisticsGroup[];
  /** 共享帳本才有；私人帳本是 `null`。依支出由大到小。 */
  people: StatisticsPerson[] | null;
}
```

### 4.2 `GET /ledgers/{ledgerId}/statistics/trend`

| 參數          | 型別               | 說明                        |
| ------------- | ------------------ | --------------------------- |
| `endMonth`    | `YYYY-MM`          | 最後一個月                  |
| `months`      | 1～24，預設 12     | 往前幾個月（含 `endMonth`） |
| `perspective` | `LEDGER` \| `MINE` | 預設 `LEDGER`               |

回應：

```ts
interface StatisticsTrend {
  ledgerId: string;
  /** 由舊到新，每個月都有，沒有交易的月份是 0。 */
  months: Array<{ month: string } & StatisticsTotals>;
}
```

| 參數       | 型別           | 說明                        |

| `endMonth` | `YYYY-MM`      | 最後一個月                  |

interface BalanceTrend {

## 5. 成功條件

- **SC-R1**（私人帳本）：§1 的「日常」→ `ledger` 與 `mine` 都是支出 $703、收入 $50,000、結餘 $49,297。
- **SC-R2**（不算的型別）：在「日常」多記一筆轉帳、一筆借出、一筆收回 → 統計的數字不變。
- **SC-R3**（共享帳本）：§1 的「家用」→ `ledger` 支出 $1,200、收入 $200；`mine` 支出 $450、收入 $200。
- **SC-R4**（每人）：「家用」的 `people` → 我 支出 $450、收入 $200；小美 支出 $750、收入 $0。每人支出加總＝`ledger.expense`，收入同理。
- **SC-R5**（沒有付款人的舊資料）：一筆 `payerPersonId` 是 `null` 的支出算給記帳的人。
- **SC-R6**（分組）：「日常」的 `expenseGroups` 有「呆帳 $500」「結清差額 $3」兩個固定分組；所有分組加總＝`ledger.expense`。
- **SC-R7**（固定分組只看自己的）：小美在「家用」免除別人 $100 → 我看到的是「未分類 $100」，小美看到的是「呆帳 $100」。
- **SC-R8**（3k 合併）：退出共享帳本、把「我付 $3,000、我的份額 $1,000」合併到「日常」→「日常」的支出多 $1,000，不是 $3,000。
- **SC-R9**（時區）：台灣時間 10/31 23:30 的交易算 10 月；11/1 00:10 的算 11 月。
- **SC-R10**（刪除與期間）：刪除的交易不算；`to` 早於 `from`、跨度超過 366 天、格式錯誤 → 400。
- **SC-R11**（權限）：不是成員 → 404；檢視者可以看；封存的帳本可以看；已退出的帳本 → 404。
- **SC-R12**（趨勢）：`endMonth=2026-10` → 12 個月，2025-11 到 2026-10，沒有交易的月份是 0；10 月那一格等於 §4.1 查 10/1～10/31 的 `ledger`。
- **SC-R13**（效能）：一個使用者、一本帳本 1 萬筆交易（含分帳、分支、刪除的），§4.1 查一整年與 §4.2 查 12 個月，各打 20 次，p95 小於 500ms（本機、API 行程內計時、不含網路）。
- **SC-R14**（首頁）：§1 第 1、2 步的數字照樣出現在首頁；共享帳本才有「我」的小字；載入失敗時不顯示 $0。
- **SC-R15**（統計頁）：§1 第 3～8 步照樣運作。
- **SC-R16**（資產趨勢）：§1 的帳戶與交易，`endMonth=2026-10` → 2025-11～2026-09 每個月 $10,000，2026-10 是 $58,190。10 月那一點等於 `GET /accounts` 所有帳戶餘額的合計（10 月之後沒有交易時）。
- **SC-R17**（資產的範圍）：別人付、記到我臨時帳戶的錢算進去；我已退出的帳本的交易不算；刪除的交易不算；別人的帳戶不算。

## 7. 界線

- **Always**：數字由後端算；所有金額用整數分加總，資料庫的加總結果轉成 `number` 前檢查是否超過安全整數；`ledger` 與 `mine`、分組、每人、趨勢用同一套歸屬規則。
- **Ask first**：改資料模型或加索引；加圖表套件；開放「全部帳本」。
- **Never**：前端自己加總或算百分比；拿交易列表的回應加總；用名字判斷是不是同一個人；在共享帳本透露別人的借還種類。
