# 3g 原型：借還頁改版的決定（暫存，定案後併入 spec）

分支 `polluxyz/debts-inline`。開發者 2026-10-07～08 看原型逐步給的回饋，先記在這裡，版面定案後寫進 `docs/specs/phase-3g-*.md` 再開 PR。

## 版面

- 交易頁分頁只剩「明細」「借還」，拿掉「結清」。借還不分帳本。
- 借還的子分頁：「總覽」「個人」「共享」「歷史」。
  - 總覽：每人總額（個人往來＋共享帳本），點對象在列下方展開明細，**沒有任何操作**。
  - 個人：只看個人往來，展開後可記一筆、免除、修改、刪除、分帳。
  - 共享：每本共享帳本一組，只列轉帳（含別人之間），不顯示淨額；**點轉帳**就在下方展開預填的結清表單，沒有「新增結清」「結清」按鈕。
  - 歷史：統一放已還清的往來紀錄與已記的結清；其他地方不再有「歷史」。
- 已還清的判斷：跟某人的往來餘額最近一次歸零，那一筆與更早的紀錄移到歷史（「餘額歸零為界」）。
- 點對象直接在列下方展開（有收合動畫），不開右側欄；「記一筆」也在下方。列右邊沒有展開記號，借貸箭頭靠右。展開區不重複箭頭、不放「往來紀錄」標題。
- 沒指向的共享帳本的人（例如「家用」的小華），列的樣式跟對象列相同。
- 最上排清空（留給 AI 功能）；帳本切換與「＋ 新增交易」移到「明細」那一排，只在明細顯示。其他頁面頂列的東西也移進內容。
- 永遠預留捲軸寬度（`scrollbar-gutter: stable`），切換分頁不左右跳動。

## 往來紀錄的符號（2026-10-08，提案頁 `docs/artifacts/step-debts-entry-symbols.html`）

- **D1（2026-10-08 修訂）**：原本選 A（「誰給了誰」金色虛線），看過原型後改成**「誰欠誰」**：所有往來紀錄與共享帳本來源都用同一種灰色實線小頭貼箭頭，從欠錢的人指向被欠的人。
  - 一般紀錄（借出、借入、代付、代收）方向看 `delta` 正負號：正＝對方 → 我，負＝我 → 對方。代付不另外標示，差別只在有沒有多一筆支出交易。
  - 還款保留線中間的「回頭」圖示，方向是被還掉的那筆欠款（對方還我＝對方 → 我）。結清差額、免除：不畫箭頭，打勾圖示＋金額。
- **操作**：每筆紀錄右邊只有「⋯」，選單裡「修改」「刪除」；分帳紀錄加「分帳」小標籤，修改打開分帳編輯、刪除走分帳刪除。總覽沒有「⋯」。
- **D2**：拿掉每筆下面的「餘額」。
- **D3**：展開區裡的共享帳本跟往來紀錄長得一樣，一行：「帳本名稱 · 人名」＋小頭貼箭頭＋金額。開發者備註：盡量統一作法，使用者習慣後就方便。
- 金額不帶正負號；完整說明（例如「我幫小明付」）放在列的可存取名稱與滑鼠提示。
- **對齊與頭貼（2026-10-09）**：展開區個人往來在上、共享帳本在下；共享帳本以帳本名稱當小標題，列上不寫人名、頭貼滑鼠提示顯示名字；兩種列共用同一排版，箭頭與金額上下對齊（共享帳本沒有日期，日期欄留空）。頭貼字在同一區塊內不衝突（小明／小華 → 明／華），展開區沿用清單算好的字。
- **撤銷（2026-10-09）**：「刪除」改名「撤銷」（軟刪除：這筆與交易作廢、餘額回到記這筆之前、資料保留）。確認框不寫說明，用「撤銷前 → 撤銷後」兩個符號預覽（畫面試算，同 W16）。歷史裡的紀錄也可以修改、撤銷（開發者要保留轉圜的餘地）。
- **還款＋結清差額綁在一起撤銷（開發者同意方向，2026-10-09）**：資料裡沒有欄位連起這兩筆，要新增 `DebtEntry.settlesEntryId`（結清差額指向它的還款），撤銷還款時一併撤銷差額；舊資料不回填。屬於 schema 與後端行為變更，排進正式 3g spec，開工前再確認。

## 操作位置與共享分頁（2026-10-12）

- 「⋯」選單不被展開區裁切：收合動畫跑完才解除 `overflow: hidden`，一收起就恢復。
- 展開區的「記一筆」「免除剩餘」放在最下面靠右：先看完紀錄再決定要不要動作。
- 共享分頁的轉帳改成方塊：每條轉帳一個圓角方塊，寬螢幕一排兩個、640px 以下一排一個，方塊裡只有置中的大箭頭。點方塊，結清表單在那一排下方全寬展開，被點的方塊加金色框；一次只開一個，再點收起。VIEWER 不可點；沒有轉帳顯示「兩清」。
- 頭貼字：同一個名字出現多次視為同一個人（小明欠三個人仍顯示「明」）。共享方塊與展開區用同一套規則。
- 開發者 2026-10-13 確認原型告一段落，進入正式 3g spec。

## 原型限制（正式版要處理）

- 已還清分組、個人分頁的 `balance ≠ 0` 過濾暫時在前端，只用 API 回傳的值判斷；正式版移到後端（API 變更，要先問）。
- 往來紀錄一次只抓 100 筆。
- 共享分頁只列目前還在的共享帳本；歷史裡的結清還不能編輯。
- Web e2e 尚未跟上（借還、連動、共享帳本分帳、3f 主線、版面）。
