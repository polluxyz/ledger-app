## 1. 目標

統計頁收支摘要的「結餘」格右下角，加一個與首頁結餘卡同款、等比縮小的金色細線圓環，讓兩頁的結餘有相同的視覺記號。圓環只是裝飾，不能擋住數字、不能吃點擊、讀屏讀不到。

### 範圍外

- 首頁結餘卡圓環（`HomeCard.module.css` 的 `.summaryDecoration`）不改。
- 收入、支出兩格不加裝飾。結餘格的淡金底色不改。
- 摘要的排法、字級、間距、斷點不改。
- 不用 container query（依容器寬度切換樣式的 CSS 語法）。桌機側欄擠窄的情況不另外處理。
- 任何後端、金額計算、API 欄位。

## 5. 界線

- Always：設計 token 與既有 CSS 變數、CSS Modules、CSP `style-src 'self'`、深淺主題、讀屏名稱不變。
- Ask first：改 TSX 結構、改摘要排法或斷點、其他頁面加圓環、API、schema、相依、CI。
- Never：圓環蓋住文字、裝飾攔截點擊或取得焦點、改金額或格式化邏輯。

## 6. 成功條件

- **SC-Q1**（W330、決策 441）：1280px 淺色與深色，結餘格右下角各有 1 個圓環。偽元素計算後 `width`、`height` 為 72px，`right` -16px、`bottom` -30px，`pointer-events` 為 `none`。收入、支出兩格沒有圓環。
- **SC-Q2**（W330）：1280px 與 601px，金額含 9 位數負數（例：`-$123,456,789`）時，結餘標籤與金額畫在圓環上方，截圖上文字筆畫沒有被線條蓋過。601px 的 `scrollWidth` 等於視窗寬。
- **SC-Q3**（決策 442）：600px、390px、320px 淺色與深色，圓環偽元素計算後 `display` 為 `none`；結餘格外觀、高度與金額位置和修改前相同（誤差 ±1px）。
- **SC-Q4**（不退步）：`StatsPage.test.tsx` 的 `結餘 -$1,000` 讀屏斷言、`stats.spec.ts` 的 SC-R21（390px 不橫向溢位）與既有統計 e2e 照樣通過。點擊結餘金額可以反白選取文字。
- **SC-Q5**：`pnpm format:check`（本次檔案）、`lint`、`typecheck`、`test`、build、web e2e 全部通過；diff 只含 `apps/web`、`docs/specs`、`docs/README.md`、`docs/handoff*`、`tasks`。附淺深 × 1280／601／390 共 6 張截圖（不進版控）。

## 7. 測試策略

- 元件測試：jsdom（測試用的模擬瀏覽器，不算真實 CSS 版面）看不到偽元素與版面，所以不加元件測試。既有讀屏斷言照跑，證明 DOM 沒變。
- e2e：在 `stats.spec.ts` 加 1 個測試，用 `getComputedStyle(element, '::before')`（讀取偽元素實際樣式的瀏覽器 API）驗 SC-Q1 的尺寸與位置、SC-Q3 的 `display: none`，並驗 601px `scrollWidth`。深淺主題沿用既有 `data-theme` 切換方式。
- 視覺：Codex 截 6 張截圖，協調者逐張核對 SC-Q2 的文字未被蓋住。
